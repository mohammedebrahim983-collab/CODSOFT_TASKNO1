
# CodSoft Java Internship - Task 1

## Project Name
Number Guessing Game

## Description
A console-based Java game in which the computer
generates a random number between 1 and 100.
The player has seven attempts to guess the number.

## Features
- Random number generation
- High and low hints
- Maximum seven valid attempts
- Score calculation
- Replay option
- Input validation
- Total rounds won

## Technologies Used
- Java
- Eclipse IDE

## How to Run
1. Open the project in Eclipse.
2. Open NumberGame.java.
3. Select Run As > Java Application.
4. Enter guesses in the Console.

## Concepts Learned
- Variables and data types
- Random number generation
- Scanner input
- If-else statements
- While loops
- Try-catch exception handling
- Basic scoring logic
